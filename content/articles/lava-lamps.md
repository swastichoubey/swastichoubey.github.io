Encryption is the process of encoding information so that only authorised parties can access it — transforming plaintext into ciphertext using an algorithm and a key. The key controls both encryption and decryption. Every new key must be random, and this is where computers have a fundamental problem.

## The Randomness Problem

Computers run on logic. Even their random number generators are deterministic — seeded from the current time in milliseconds, then run through a formula. Predictable in principle. This creates a genuine security issue: if your encryption keys are generated by a predictable process, they can be attacked by someone who knows or can guess the seed.

```js
// Simplified Math.random() — not actually random
function nextRandom(seed) {
  seed = (seed * 25214903917 + 11) % Math.pow(2, 48)
  return seed / Math.pow(2, 48)
}
```

Randomness in encryption matters for several compounding reasons: it adds complexity that resists brute-force attacks, prevents patterns from emerging in ciphertext, strengthens key generation, and resists cryptanalysis. A lack of true randomness at the key generation step propagates weakness through everything downstream.

## The Lava Lamp Solution

To produce unpredictable data, you need a source of physical randomness — something outside the deterministic logic of the computer itself. The real world is an excellent random data generator. Cloudflare's specific solution: a wall of 100 lava lamps with a camera pointed at them.

Lava lamps are constantly, irreproducibly random — the "lava" never takes the same shape twice. The camera photographs the wall at regular intervals. Each digital image is stored as a series of numbers (one per pixel), producing a string of values that are genuinely unpredictable. Cloudflare's servers use these as a seed for generating SSL/TLS encryption keys.

> The camera takes photos of the lamps at regular intervals and sends the images to Cloudflare servers. Each image becomes a string of totally random numbers that the servers use as a starting point for creating secure encryption keys.

Besides being aesthetically on point, the wall provides strong, sufficiently random entropy for encryption at scale. An earlier version of the same idea was introduced by a company called Silicon Graphics — Cloudflare extended it.

---

What I find interesting here is that the solution to a fundamental limitation of computing is to pipe in the physical world. Not a software fix — a camera. The randomness was always available; it just required looking outward rather than inward.
